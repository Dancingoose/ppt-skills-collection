# 画布格式（Canvas Formats）

> **axi-front-design 执行层的画布规格**。吸收自 ppt-master（hugohe3，**MIT License**）的 `references/canvas-formats.md`，改写成合集 1920×1080 基准。
> 核心规则：**画布形态决定一切**——比例、字号基准、布局流向、边距，随画布变，不硬套。

## 与布局库 / 设计系统的关系

- `layout-library.md` 定**每页怎么排**（线框）——布局库的 41 个布局默认按 16:9 设计，**用于非 16:9 画布时须按本文件的布局原则调整**。具体调整规则见下方「非 16:9 画布布局适配」。
- `design-system.md` 定**配色/字体/圆角**——token 体系不变，但**字号基准随画布缩放**
- 本文件定**画布本身的规格**（尺寸/比例/流向/边距/基准）

## 一、画布格式速查表

| ID | 格式 | 尺寸 | 比例 | 用途 |
|----|------|------|------|------|
| `ppt169` | PPT 16:9 | 1920×1080 | 16:9 | 业务演示、会议、汇报 |
| `ppt43` | PPT 4:3 | 1024×768 | 4:3 | 传统投影仪、学术报告 |
| `xiaohongshu` | 小红书 | 1242×1660 | 3:4 | 图文分享、知识贴 |
| `moments` | 朋友圈 / IG | 1080×1080 | 1:1 | 方图、品牌展示 |
| `story` | 故事 / 抖音 | 1080×1920 | 9:16 | 竖版故事、短视频封面 |
| `wechat` | 公众号头图 | 900×383 | 2.35:1 | 公众号文章封面 |
| `banner` | 横幅 | 1920×1080 | 16:9 | 网页横幅、数字屏 |
| `a4` | A4 打印 | 1240×1754 | 1:√2 | 打印海报、传单 |

> `ppt169` 是合集规范宽屏基准（1920×1080），同比例的 `banner` 是不同坐标系。**同一 deck 内所有页必须用同一画布。**

## 二、画布选择决策树

```
内容用途?
├── 演示
│   ├── 现代设备 → ppt169（16:9）
│   └── 传统设备 / 学术 → ppt43（4:3）
├── 社交分享
│   ├── 小红书 → xiaohongshu（3:4）
│   ├── 朋友圈 / IG → moments（1:1）
│   └── 故事 / 抖音 → story（9:16）
└── 营销物料
    ├── 公众号头图 → wechat（2.35:1）
    ├── 横幅 → banner（16:9）
    └── 打印 → a4（1:√2）
```

## 三、布局原则（按形态）

### 横屏（16:9 / 4:3 / 2.35:1）
- **视觉流向**：Z 型，从左到右
- **边距**：40–80px（1920 基准下 64–128px）
- **布局**：多列、左右分栏、网格
- **卡片尺寸**（16:9）：单行 530–600px 高，双行 265–295px 高

### 竖屏（3:4 / 9:16）
- **视觉流向**：从上到下
- **边距**：60–120px（小红书基准下放大）
- **布局**：单列、上下分栏、卡片堆叠
- **卡片尺寸**（3:4）：高 400–600px，间距 40–60px

### 方图（1:1）
- **视觉流向**：中心辐射
- **边距**：60–100px
- **核心区**：约 800×800px

## 四、格式专属设计

| 格式 | 标题区 | 内容区 | 特别说明 |
|------|--------|--------|----------|
| PPT 16:9 | 80–100px | 全宽利用 | 页码右下 |
| 小红书 3:4 | 180–240px（加粗） | 上下留白充裕 | 底部品牌区 120–160px |
| 朋友圈 1:1 | 200–280px | 中心 500–600px | 底部二维码区 150–200px |
| 故事 9:16 | — | 中部 1500px | 顶部安全区 120px，底部 180px |
| 公众号头图 | 居中/左对齐 48–72px | — | 图在右或作背景 |

## 五、字号基准随画布缩放（关键）

**16:9 的正文 24px 不能直接搬到竖屏**。每个画布按阅读模式定基准：

| 画布 | 阅读模式 | 正文基准 | 标题基准 |
|------|---------|---------|---------|
| ppt169 | 近读 / 商务 / 投影 | 24–28px | 64–80px |
| ppt43 | 近读 / 学术 | 22–26px | 60–72px |
| xiaohongshu | 手机近读 | 28–32px | 56–72px |
| moments | 手机近读 | 26–30px | 52–68px |
| story | 手机近读（大屏竖） | 34–40px | 72–96px |
| wechat | 手机近读 | 22–26px | 48–72px |
| banner | 远观 / 展示 | 20–24px | 56–80px |
| a4 | 打印近读 | 16–20px | 40–56px |

> 基准来自确认的画布，不是"推荐画布"。转换画布时先重新定字号基准，再排版。

### 非 16:9 画布布局适配规则

布局库 41 个布局的线框和比例默认基于 1920×1080（16:9）。用于其他画布时：

**竖屏（3:4 / 9:16）**：
- 多列布局（A3/A5/B4/B6/B7/B15/B16/B19）→ 列数减半或改为堆叠（如 3×2 → 单列堆叠，4 列 → 2 列）
- 左右分栏（A4/A10/B5/B8/B13/B22）→ 改为上下分栏（标题在上、内容在下）
- 封面（A1/B1）→ 垂直居中内容区高度增大，字号按「字号基准表」调整
- 横向时间线（B11）→ 改为纵向时间线（B2 结构）
- C 系列 Bento：双列非对称（C2/C3）→ 改为上下主辅结构；三列等分（C4）→ 单列堆叠

**方图（1:1）**：
- 多列布局保持列数但缩小卡间距；封面居中放大字号
- Hero+Grid（C5）和其他 Bento 混合布局保持卡片比例，按中心辐射原则重新分布

**横幅（2.35:1）**：
- 极窄高度下只用单行内容：大字报（A3/B20）、横向时间线（B11）、极简陈述（B3）
- 禁多列网格和堆叠卡片；卡片最小高度 ≥ 30vh

**A4 打印（1:√2）**：
- 所有布局内间距放大（24px → 32px gap），正文按打印基准 16-20px
- 禁 ECharts/Three.js 等交互增强（打印不可交互），改用静态 SVG 图表

## 六、HTML 实现要点

```css
/* 以 1920×1080 为设计稿，transform: scale() 适配任意视口（已约定） */
.deck { width: 1920px; height: 1080px; transform-origin: top left; }

/* 竖屏画布改基准 */
.deck.xiaohongshu { width: 1242px; height: 1660px; }
.deck.story { width: 1080px; height: 1920px; }
```

- 非 16:9 画布：改 `.deck` 宽高，正文/标题基准用上表数值
- 同一 deck 内**不混用画布**
- `transform: scale()` 自适应视口逻辑对所有画布通用
