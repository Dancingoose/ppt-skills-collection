# 网络配图或无图流程

> 配图不是默认项。只允许使用用户提供的图片，或来自网络且许可证、来源页面和用途均可核验的图片。严禁生成、索取或使用 AI 生成图。ECharts 数据图表不适用本流程。

## 逐页决策

在选版式前，为每一页需要非数据视觉素材的页面写入任务目录的 `image-sourcing-plan.md`。每条记录只能是以下三种之一：

| 决策 | 适用条件 | 必填记录 |
|---|---|---|
| `supplied-image` | 用户素材中已有可用图片 | 文件路径、素材来源、页面用途、裁切比例 |
| `web-search` | 图片有助于理解且可从网络取得 | 页面用途、检索关键词、候选平台、候选 URL、许可证状态、作者/归属要求、裁切比例 |
| `no-image` | 图片不能明显提升内容，或没有许可明确的合适素材 | 原因、无图版式、替代视觉元素 |

网络检索建议优先指向可单独查看许可信息的原始资源页，例如 Unsplash、Pexels、Wikimedia Commons 或机构官方媒体库；不得使用搜索结果缩略图、社交媒体转发图、来源不明的转载图或受限新闻图片。不得编造候选 URL、许可证或归属信息。下载或嵌入前检查该素材页的当前许可证、署名要求、商业/编辑用途限制和人物肖像限制；无法核实则改为 `no-image`。

建议搜索不等于可以使用。先向制作者呈现逐页候选和许可状态；获准后，把最终 URL、许可证、归属文本和本地文件路径写回 `image-sourcing-plan.md` 与相应页面的 `layoutEvidence.sourceRefs`。保留图片原始比例，使用与槽位匹配的裁切，不将装饰性图片当作事实证据。

## 无图路径

选择 `no-image` 后，改用排版、留白、色块、真实文字层级、时间线或图标表达。不得保留“待补图”占位符进入交付；若页面依赖真实照片才成立，停止扩展并请制作者提供素材或批准网络候选。
