# 配图流程（Image Generation）

> **axi-front-design 执行层的配图指南**。吸收自 baoyu-design（JimLiu/宝玉，**MIT License**）的 `generate-images.md`——配图流程的单一事实来源。
> 核心原则：**配图是按需选配，不是自动默认**；干净的占位符胜过一张糟糕的生成图。

## 何时生成（按需，非默认）

生成当内容"值得一张图"：
- 概念隐喻 / 比喻
- hero 图 / 章节大图
- 贯穿整套 deck 的吉祥物 / 角色
- 应用图标
- 纹理
- 真正的信息图

**必须提供"无图 / 极简"路径**。在两阶段确认（Phase 2）里问一句：要不要配图、什么风格。若内容明显不需要（密集数据 UI、简短内部评审、明确"保持极简"），**不要问，直接跳过**。

## 分工：什么该生成，什么该留在 HTML

现代生图后端渲染文字已经很可靠（**包括中文/CJK**），不要因为"raster 做不了文字"就回避——文字密集的真正信息图（标题、标签、callout、中文文案）是生成的好用途。

但**必须保持可编辑、可选、像素精确、数据绑定**的内容属于 HTML/CSS，不生成：
- 用户要编辑的表格
- 精确财务数字
- 绑定数据的图表
- 密集小字

信息图的叙述文字和标签不需要那种精确度——**可以生成**。否则把生成留给 raster 擅长的：概念场景、角色/吉祥物、hero/章节图、纹理、真正信息图。

**整套 deck 的所有生成图保持一个共享的风格/身份块**，让外观和性格一致。

## 后端检测（按顺序）

1. **当前请求覆盖** — 用户本条消息指定后端，用它的
2. **已存偏好** — 宿主配置了可用后端，用它
3. **自动选择** — 检查可用工具清单，按序：
   - Codex `imagegen`（官方 raster 后端，优先级最高）
   - Cursor `GenerateImage`（原生工具，无宽高比参数，在 prompt 里写目标尺寸/比例）
   - 其他运行时原生工具（Hermes `image_generate` 等）
   - 否则用已安装的 `baoyu-image-gen` skill（通用 raster 生成）
4. **都没有** — 告诉用户，问怎么办。**不要静默降级。**

## 硬规则

- **先写 prompt 文件**：调用任何后端前，把每张图的完整最终 prompt 写入 `prompts/NN-{type}-[slug].md`。这是可复现记录，且让你能换后端而不重写 prompt。
- **绝不**用 SVG / HTML / canvas 顶替决定要生成的 raster 图。后端不可用就按第 4 步问用户，不要发 `<svg>` 或 CSS 艺术顶替。这包括"像图表"的内容——调用方已决定要 raster。
- **文字要写对，别事后涂改**：文字通常渲染得很好（含中文）——把精确字符串（确切字符）放进 prompt，让后端逐字拿到。只有标签仍错时才用更明确的 prompt 重新生成，**不要**修补位图。

## 输出与放置

- 保留的图存进项目内 `imgs/`，prompt 文件存 `prompts/`，保持交付自包含
- 图放在白色或对比色区域；整页艺术图 aspect-fill，截图/图 aspect-fit
- **每张生成图都要查看并确认加载成功**再交付

## 与合集工作流的衔接

- **触发点**：axi-front-design 两阶段确认的 Phase 2「图片来源」字段选「AI 生图」时启用
- **执行位置**：方案预览选定后、展开全量页面时，为需要配图的页面生成
- **图片比例**：必须匹配布局库的图片槽位（A 系列 16:10/4:3/3:4，B 系列 21:9/16:10，Bento 卡内图）
- **与 ppt-visual-effects 的区别**：本流程生成**静态位图素材**（插图/图标/信息图/角色），ppt-visual-effects 注入的是**交互式图表/3D/着色器**——两者互补
- **数据页图表决策规则**：数据展示页同时有"需要图表"的信号时：
  - 优先走 ppt-visual-effects 的 ECharts 交互式图表（可导出 PPTX 时截图嵌入）
  - 只在以下情况才用本流程生成静态信息图：① 用户明确要求"生成一张信息图" ② 内容需要合成式视觉叙事（非纯数据） ③ ppt-visual-effects 判断不宜用交互图表（如 A4 打印画布）
  - 两者不同时用于同一页——避免图表重复
- **导出注意**：生成图导出 PPTX 时作为媒体直传嵌入（html-to-pptx 的媒体档）

## 外部依赖标注

配图需要**外部生图后端**，不是合集自带能力：
- Codex / Cursor 原生生图工具（需对应环境）
- `baoyu-image-gen` skill（需单独安装）
- Gemini `generate_image` 工具（需 Google 环境）
- 或任何 OpenAI 兼容生图 API（如 gpt-image-2）

> 若用户环境没有可用生图后端，**回退到占位符**，不生成、不硬顶替。
