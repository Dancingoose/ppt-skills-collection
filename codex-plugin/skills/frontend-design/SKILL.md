# Frontend Design Review For PPT

Use the collection root named by `PPT_WORKFLOW_ROOT`; when it is unset, derive it from this installed package. Follow `ppt-workflow/SKILL.md` and read `design-assets/frontend-design/SKILL.md` as the authority.

1. Review every design decision, including explicit-style fast paths.
2. Check the existing passport, theme, typography, layout choice, and preview for generic-template drift or HTML-first implementation risks.
3. Record findings through the existing review artifacts and gates. Do not introduce an independent decision workflow.
